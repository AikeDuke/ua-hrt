# Як допомогти проєкту
Ви можете допомогти з виправленням помилок у тексті, написанням нових статтей, або з технічною стороною вебсайту.

## Як додати нову статтю
1. Створіть новий файл у директорії [src/articles/](/src/articles/) з розширенням `.md` (Markdown). Наприклад: `src/articles/legal/my-article.md`. 
2. Додайте цей текст на самому початку. Замініть заголовок на той, що підходить вашій статті:
```yaml
---
title: Моя стаття
---
``` 
3. Напишіть решту!
4. Додайте посилання на сторінку у шаблоні [sidebar.html](/src/_includes/templates/sidebar.html):
```html
...
<button>Юридичні аспекти</button>
<div>
    <ul>
        ...
        <!-- Додайте тільки рядок нижче, адаптований під ваше посилання та назву -->
        <li><a href="/articles/legal/my-article/">Моя стаття</a></li>
    </ul>
</div>
```
5. Збережіть ваші зміни через commit та зробіть pull request. За можливістю напишіть опис комміту англійською. Пусті та беззмістовні описи змін не прийматимуться.

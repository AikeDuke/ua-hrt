# Як допомогти проєкту
Ви можете допомогти з виправленням помилок у тексті, написанням нових статтей, або з технічною стороною вебсайту.

## Як додати нову статтю
1. Створіть новий файл у директорії [src/articles/](/src/articles/) з розширенням `.md` (Markdown). Наприклад: `src/articles/legal/my-article.md`. 
2. Додайте цей текст на самому початку. Це [front matter](https://www.markdownlang.com/advanced/frontmatter.html) — частина документу, що містить метадані.
```yaml
---
title: Заголовок # Не має бути занадто довгим.
body_title: Довший заголовок # Опціональний параметр, заголовок у тілі HTML документу.
tags: Юридичні аспекти # Категорія, у якій має відображатися документ.
order: 20 # Відносний порядок відображення у боковому меню.
---
``` 
3. Напишіть решту!
4. Якщо ви додали статтю в існуючу категорію, стаття буде автоматично додана в бокове меню. 
Якщо ви створили нову категорію, додайте її у [sidebar.njk](src/_includes/templates/sidebar.njk):
```nunjucks
...
{# Категорії додавати сюди #}
{{ renderSidebarCategory("Моя категорія") }}
...
```
5. Збережіть ваші зміни через commit та зробіть pull request. За можливістю напишіть опис комміту англійською. Пусті та беззмістовні описи змін не прийматимуться.

# transition.in.ua
Resources for gender transition in Ukraine.

[Contributing to the project](/CONTRIBUTING.md)

## Running locally
You need to have [npm](https://nodejs.org/en/download) installed on your system.

```shell
npm ci
npx @11ty/eleventy --serve
```
The output will tell you where the website is served (most probably http://localhost:8080/).

# transition.in.ua
Ресурси для трансгендерного переходу в Україні.

[Допомога проєкту](/CONTRIBUTING.md)

## Як запустити сайт локально
На вашій системі має бути встановлений [npm](https://nodejs.org/en/download).

```shell
npm ci
npx @11ty/eleventy --serve
```
У виводі програми буде написано, за якою адресою доступний вебсайт (скоріш за все http://localhost:8080/).
